# **App Name**: OSO App: Learn & Deliver

## Core Features:

- Core Navigation: Tab-based navigation: Home, Study, Delivery, Circle, and Profile.
- Home Screen: Home Screen: Daily updates, shortcuts, motivational quote card in bilingual format (English + Hindi).
- Brain Scan: OSO Brain Scan™: AI engine that acts as a tool checking student’s clarity, attention span, and stress level. Generates weekly “Brain Fitness Report”.
- Mind Diary: OSO Mind Diary™: Emotional check-ins using emojis, self-reflection, and motivational quotes/audio in bilingual format.
- Peer Match: OSO Circle™: AI Peer Match system grouping students by location + subject.
- Stationery Delivery: Delivery Section: Zomato/Swiggy style UI for ordering stationery from local vendors.
- Courses: Courses Section: AI + Coding, NCERT syllabus, previous year papers, with voice-to-notes feature.

## Style Guidelines:

- Primary color: Blue (#144EE3) to convey trust and knowledge.
- Background color: Off-white (#F9F9F9) for clean readability.
- Accent color: Yellow (#FFD000) to highlight key CTAs and interactive elements.
- Body and headline font: 'PT Sans', sans-serif, offering both a modern look and approachability.
- Use bold, custom icons for fast navigation (books, brain, rocket, pencil, smiley).
- Youth-friendly design with clear CTA buttons and a clutter-free UI.
- Subtle loading animations for Brain Scan and Pocket School to keep users engaged.
